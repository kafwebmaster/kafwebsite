# ヘッドレス CMS 移行プロジェクト 概算見積書(ドラフト)

作成日: 2026-07-24
対象: KADOMA ART FES 公式サイト ヘッドレス CMS 移行(案C)
根拠計画書: `docs/headless-cms-migration-plan.md`(フェーズ M0〜M9)

> 本書は**初回のラフ見積(概算)**である。単価・体制は仮置きのため、
> 発注形態(外部委託 / 内製 + Claude Code 活用)が決まり次第、確定版に更新する。

---

## 1. 見積の前提条件

| 項目 | 前提 |
|---|---|
| スコープ | 計画書のフェーズ M0〜M9 一式(Astro 化 / microCMS 連携 / アーカイブ新機能 / Instagram 連携 / 検証 / 本番切替 / 手順書) |
| 見た目 | 現行デザイン完全維持(新規デザイン制作は含まない) |
| 体制(仮) | 開発エンジニア 1 名 + ディレクション(進行管理・レビュー) |
| 基準単価(仮) | エンジニア **50,000 円/人日**、ディレクション **45,000 円/人日** |
| 過去アーカイブ初期データ | KAF4(2024)1 大会分の取り込みを含む。KAF1〜3 の遡及は別途(オプション) |
| 素材 | 文章・画像素材は発注者(実行委員会)側で用意 |
| 除外 | 新規デザイン制作 / 写真撮影 / 原稿執筆 / KAF1〜3 アーカイブ遡及 / 公開後の保守運用 |

### 4-B. 内製 + Claude Code 活用の場合(参考)

開発作業の大半を Claude Code(本セッションのような形)で実施し、人間は**指示出し・プレビュー確認・受入テスト**に専念する場合:

| 項目 | 内容 | 概算 |
|---|---|---:|
| 人間の稼働 | 指示・確認・テスト(約 4〜6 人日相当) | 委員会内の稼働(外部支出なし) |
| Claude 利用料 | Claude Pro/Max 等のサブスクリプション 1〜2 ヶ月分 | 約 3,000〜30,000 円 |
| microCMS / Cloudflare / Astro | 無料枠 | 0 円 |
| **外部支出合計** | | **約 3,000〜30,000 円** |

> これまでのリファクタリング(フェーズ1〜3)と同じ進め方。品質確認の責任は委員会側が持つ。

## 6. 支払・契約に関する備考(仮)

- 検収条件: M7 の検証項目(表示一致・URL 一致・管理画面更新テスト)の全項目パス
- 4-A の場合の支払時期(例): 着手時 50% / 検収後 50%
- 本見積の有効期限: 発行日より 3 ヶ月
- microCMS 無料枠の仕様(3 席・API 5 個・転送 20GB/月)が変更された場合は再協議

## 7. 確定版に向けて決めること

1. 発注形態: **4-A(外部委託)か 4-B(内製 + Claude Code)か** ← 金額が桁で変わる最重要判断
2. 4-A の場合: 委託先と実際の単価(本書の単価は市場相場ベースの仮置き)
3. スケジュール優先度: 標準(7〜8 週)か短縮(3〜4 週)か
4. オプション(KAF1〜3 遡及)を初回スコープに含めるか
