## 4. 本件で実現すること

| 現状の課題 | 導入後 |
|---|---|
| サイト更新のたびにファイル編集とサーバー操作が必要 | ブラウザの管理画面から入力するだけで更新完了 |
| Web の知識がないメンバーは更新できない | 専門知識なしで全メンバーが更新可能 |
| 更新漏れによる情報の不整合が発生(過去に発生実績あり) | 開催日等は 1 箇所の変更で全ページへ自動反映 |
| 過去大会の記録が個別ページで分散 | 年度別アーカイブとして体系的に蓄積・閲覧可能 |
| Instagram の投稿はサイトに反映されない | 公式アカウントの投稿を自動表示 |
| アクセス状況が把握できない | アクセス解析を導入し、閲覧・離脱状況を可視化 |

## 7. 前提条件・作業分担

### 発注者様にご対応いただく事項
- 各種サービスアカウントの開設・契約(いずれも無料枠の範囲)
- 掲載する文章・画像素材のご提供
- 確認用 URL での内容確認・ご承認
- 公式 Instagram アカウントの設定(ビジネスアカウントへの切替が必要な場合)

### デザインの取り扱い
- 新規に追加するページ・表示パーツ(アーカイブ機能等)のデザイン設計は**本見積に含まれます**(内訳 No.2)
- 制作方針は**現行サイトのデザインを踏襲**し、既存ページとの統一感を保ちます
- ロゴ・配色・書体・サイト全体のデザイン方針は現行のまま変更しません

### 本見積に含まれないもの
- サイト全体のデザイン刷新、ブランディング変更(ロゴ・配色・デザイン方針の変更)
- 写真撮影、原稿執筆
- KAF1〜KAF3 の過去大会アーカイブの遡及取り込み(オプション)
- 納品後の保守運用(別途ご相談)
