## 4. 本件で実現すること

| 現状の課題 | 導入後 |
|---|---|
| サイト更新のたびにファイル編集とサーバー操作が必要 | ブラウザの管理画面から入力するだけで更新完了 |
| Web の知識がないメンバーは更新できない | 専門知識なしで全メンバーが更新可能 |
| 更新漏れによる情報の不整合が発生(過去に発生実績あり) | 開催日等は 1 箇所の変更で全ページへ自動反映 |
| 過去大会の記録が個別ページで分散 | 年度別アーカイブとして体系的に蓄積・閲覧可能 |
| Instagram の投稿はサイトに反映されない | 公式アカウントの投稿を自動表示 |
| アクセス状況が把握できない | アクセス解析を導入し、閲覧・離脱状況を可視化 |

## 6. スケジュール

### 全体の流れ

| 時期 | 内容 | 主担当 |
|---|---|---|
| 2026年8月上旬 〜 9月中旬(約1.5ヶ月) | **構築作業** | 弊方 |

### 構築作業の内訳(8月上旬〜9月中旬)

| 週 | 内容 |
|---|---|
| 第 1 週 | 環境構築、サイト基盤の移行実装(前半) |
| 第 2 週 | サイト基盤の移行実装(後半) |
| 第 3 週 | 管理画面の構築、データ連携(前半) |

### 補足

- 構築期間中は、各週末に確認用 URL にて進捗をご確認いただきます
- **構築期間中および準備期間中、現在の公式サイトは通常どおり公開され続けます**(本番切替まで一切影響しません)
- 準備期間(9月中旬〜10月下旬)は、実行委員会様に管理画面から画像・記事等をご登録いただく期間です。この間の**ご質問対応・軽微な修正は本見積に含みます**
- 本番公開日は、実行委員会様のご都合に合わせて調整可能です

### ご注意

本番切替(11月上旬)までの間、**現行サイトの更新が必要になった場合は、従来どおりの方法**(ファイル編集)での対応となります。切替後は管理画面からの更新に一本化されます。

## 7. 前提条件・作業分担

### 発注者様にご対応いただく事項
- 各種サービスアカウントの開設・契約(いずれも無料枠の範囲)
- 掲載する文章・画像素材のご提供
- 確認用 URL での内容確認・ご承認
- 公式 Instagram アカウントの設定(ビジネスアカウントへの切替が必要な場合)

### デザインの取り扱い
- 新規に追加するページ・表示パーツ(アーカイブ機能等)のデザイン設計は**本見積に含まれます**(内訳 No.2)
- 制作方針は**現行サイトのデザインを踏襲**し、既存ページとの統一感を保ちます
- ロゴ・配色・書体・サイト全体のデザイン方針は現行のまま変更しません

### 本見積に含まれないもの
- サイト全体のデザイン刷新、ブランディング変更(ロゴ・配色・デザイン方針の変更)
- 写真撮影、原稿執筆
- KAF1〜KAF3 の過去大会アーカイブの遡及取り込み(オプション)
- 納品後の保守運用(別途ご相談)
