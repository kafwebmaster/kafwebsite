# サイト更新ガイド(運営スタッフ向け)

最終更新: 2026-09-12
対象: KADOMA ART FES 公式サイト https://kadoma-artfes.jp/

このガイドは、**Web の専門知識がない方でもサイトを更新できるようにする**ためのものです。
ふだんの更新はすべて microCMS(コンテンツ管理画面)から行えます。

---

## 1. サイトの仕組み(30秒で理解)

```
microCMS で内容を編集して「公開」を押す
        ↓ (自動)
数分後、サイトに反映される
```

- 編集するのは **microCMS の管理画面**(https://kadoma-artfes.microcms.io/)だけです
- 「公開」を押すとサイトが自動で作り直されます。**待ち時間は 2〜5 分**です
- コードや FTP は一切触りません

> 確認用サイト(ステージング)と本番の 2 つがあります。
> 左下に黄色い「開発中」の帯が出ているのが**確認用**、出ていないのが**本番**です。

---

## 2. ふだんの更新(microCMS でできること)

### 2-1. お知らせを追加する

1. microCMS → **お知らせ** → 「追加」
2. 日付(例: 2026/09/26)・カテゴリ・本文を入力
3. リンク先があれば「リンク」にページ名(例: `kaf_mmg.html`)
4. **公開** → 数分でトップページの「活動報告」に載ります

### 2-2. 募集ステータスを変える(コンテストの時期ごと)

microCMS → **サイト設定** → 以下の 2 つを変更して公開:

| 時期 | 募集ステータス(表示名) | 募集状態(内部) |
|---|---|---|
| 募集開始前 | `11月20日受付開始` など | closed |
| 募集開始(11/20〜) | `募集中` | open |
| 締切後(2027/2/21〜) | `募集終了` | closed |

メニューの「作品募集(◯◯)」とページの見出しが自動で変わります。

### 2-3. 日付・会場・大会名などを変える

microCMS → **サイト設定** の該当フィールドを書き換えて公開するだけです。
どのフィールドがサイトのどこに出るかは、各フィールドの説明文を参照してください。

### 2-4. 画像を差し替える(フライヤー・メインビジュアルなど)

1. microCMS → **サイト設定** → 該当の画像フィールド
2. 画像をドラッグ&ドロップで差し替え → 公開
3. **日本語のファイル名でも問題ありません**

| フィールド | サイトのどこに出るか |
|---|---|
| メインビジュアル | トップ最上部の大きな画像 / アートラウンジページ |
| フライヤー(表) | トップのフライヤー枠 |
| フライヤー(全体) | イベント開催情報ページ |
| 協賛ポスター | 協賛・応援ページ(未登録の間はメインビジュアルが出ます) |
| 募集バナー / 応募要項サムネイル | 作品募集ページ |

### 2-5. 協賛企業を追加・削除する

microCMS → **協賛** で追加・削除。表示順を指定したい場合は「表示順」に数字(小さいほど上)。

### 2-6. 過去大会の写真ギャラリーを登録する(年 1 回)

1. microCMS → **過去大会アーカイブ** → 「追加」
2. 開催年(数字)・大会名・開催期間・紹介文を入力
3. **写真を必ず 1 枚以上登録**(写真ゼロだと「準備中」扱いで表示されません)
4. 公開 → メニューの「◯◯イベント風景Photoギャラリー」が自動で最新大会に切り替わり、
   前の大会は自動で「アーカイブ」へ移ります(2 大会目以降で「アーカイブ」メニューが出ます)

## 3. 反映されないときのチェックリスト

1. **「公開」を押しましたか?**(下書き保存では反映されません)
2. **5 分待ちましたか?**(作り直しに数分かかります)
3. **シークレットウィンドウで見ていますか?**(通常ウィンドウは古い表示が残ることがあります)
4. それでも反映されない → Cloudflare の管理画面 → 対象プロジェクト → Deployments →
   最新の行の「…」→ **Retry deployment**(同じ内容で作り直し。CMS の最新値が取り込まれます)
5. 解決しなければ Web 担当へ連絡

## 4. 表示がおかしくなったときの緊急復旧(1 分)

Cloudflare 管理画面 → **kafwebsite**(本番)→ Deployments →
正常だった時点のデプロイの「…」→ **Rollback to this deployment**。
その時点の表示に即時で戻ります。焦らず戻してから Web 担当へ連絡してください。

---

## 5. 年度更新(大会が変わるとき)の手順

次回(KAF7 本番サイト化)を想定した全体の流れです。所要 20〜30 分。

1. **サイト設定**の値を新大会に更新(大会名・年度・開催日・会場・入場料・時間)
2. **画像**を新大会のものに差し替え(2-4 の表を参照)
3. **前大会の写真**を「過去大会アーカイブ」に登録(2-6)
4. **募集関連**(締切・展示期間・搬入時期・フォーム URL)を新コンテストの値に更新
5. **応募用紙 PDF** の差し替え → Web 担当へ依頼(サイト本体と一緒に管理しているため)
6. 募集要項の文章(参加資格・規約など)の変更 → Web 担当へ依頼
   ※管理画面だけで変えられるようにする対応を予定しています

## 6. やってはいけないこと

- microCMS の **API スキーマ(フィールドの追加・削除・ID 変更)を触らない**
  (サイトとの対応関係が壊れます。必要な場合は Web 担当と一緒に)
- フィールドを「必須」に変えない(過去に保存できなくなる事故がありました)
- 応募用紙 PDF を microCMS にアップロードしない(**PDF は有料**のため、サイト本体で管理しています)
